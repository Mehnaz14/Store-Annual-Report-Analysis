This project focuses on analyzing store sales data to uncover meaningful insights, identify trends, and support data-driven decision-making. 
The analysis includes data cleaning, transformation, and visualization.
Objectives:
Analyze sales performance over time
Identify top-performing products/categories
Understand customer purchasing behavior
Generate actionable business insights
Key Insights:
Sales increased during specific months (seasonal trends)
Certain products/categories contributed most to revenue
Customer purchase behavior shows repeat buying patterns
